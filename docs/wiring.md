# 配線

トランジスタ技術の記事の接続図を前提にした配線です。配線作業中は必ずバッテリーを外してください。

## I2C信号

ATOMS3RまたはAtomS3のPORT.Aを使用します。G7、G8、GNDは4台のRoller485で共通にし、4台は同じI2Cバスを共有します。各Roller485はI2Cアドレスで識別します。

## ATOMS3R/AtomS3への5 V給電

ATOMS3R/AtomS3への5 Vは、4台のRoller485のうち任意の1台だけから供給します。複数のRoller485の5 V出力を並列接続しないでください。4台で共通にするのはG7、G8、GNDです。ATOMS3R/AtomS3へ5 Vを供給しない残り3台の5 V線は接続しません。

市販のGrove 4線ケーブルをそのまま4台分並列接続すると、5 V線まで並列接続される可能性があります。必要な信号線だけを接続できる自作ケーブルまたは分岐配線を使用してください。

## 7.2 V駆動電源

7.2 Vバッテリーを4台のRoller485のPWR485入力へ分配します。バッテリーのプラスを各PWR485電源入力へ、マイナスを各Roller485のGNDへ接続してください。ATOMS3R/AtomS3、Roller485、バッテリーのGNDは共通にします。

電源の極性を接続前に確認してください。逆接、短絡、配線抜けがある状態で電源を入れないでください。

Roller485の電源仕様とI2Cアドレス設定は、[M5Stack公式資料](https://docs.m5stack.com/ja/guide/motor_ctl/roller485/roller485)を参照してください。

## Roller485の配置とI2Cアドレス

| 位置 | 説明 | I2Cアドレス |
| --- | --- | --- |
| LEFT | 左外側 | `0x64` |
| LEFT2 | 左内側 | `0x65` |
| RIGHT2 | 右内側 | `0x66` |
| RIGHT | 右外側 | `0x67` |

アドレスの設定方法は、上記のM5Stack公式資料を参照してください。

## コントローラーとの通信

Atom JoyStick コントローラーと本体側 AtomS3R/AtomS3 は、ESP-NOW のチャンネル 3 で無線接続します。
