# 安全上の注意

倒立振子は電源投入後や制御開始時に突然動く可能性があります。通電中はロボットの周囲に十分な空間を確保し、作業中は目を離さないでください。

## バッテリーと起動確認

- 損傷、変形、膨張、液漏れのあるバッテリーは使用しないでください。
- 本体を安定した台に置き、4輪を浮かせてからバッテリーを接続してください。
- 起動確認中は、手、衣服、ケーブル、工具を車輪へ近づけないでください。
- 起動確認が終了する前に、本体を台から持ち上げないでください。
- 回転しない車輪、異常な回転方向、異音、引っ掛かりがある場合は、倒立制御を開始せず、本体のバッテリーを外してください。

## 操作と終了

- 倒立制御を開始する前に、周囲の人と障害物を確認してください。
- 本体を持つ場合は、車輪や可動部から離れた位置を持ってください。
- 終了時は本体を保持してから右上ボタンで制御を停止してください。
- 車輪停止後に本体バッテリーを必ず外してください。
- バッテリーを外してからコントローラーを切ってください。
- 通電したまま無人で放置しないでください。

## ファームウェアの安全機能

- 電源投入直後に動き出さないよう、本体側は有効なESP-NOWパケットを受信するまでモーターを起動しません。
- ESP-NOWの受信タイムアウトを検出すると、モーターを停止します。
- 傾き角が転倒検出しきい値を超えると、モーターを停止します。
- Roller485の初期化に失敗した場合、制御タスクは開始されません。
