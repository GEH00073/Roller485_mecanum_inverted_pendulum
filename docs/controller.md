# コントローラー操作

Atom JoyStickコントローラーで倒立振子を操作します。起動時は通常モードです。

## 起動前の準備

1. コントローラーの電源を入れます。
2. 本体を安定した台に置き、4輪を床や台から浮かせます。
3. 周囲に人や障害物がなく、手、衣服、ケーブル、工具が車輪から離れていることを確認します。

## 起動手順

1. 本体のバッテリーを接続します。
2. 4台のRoller485が1台ずつ順番に回転することを確認します。
3. 続いて、ファームウェアの実装どおり4輪が同時に回転することを確認します。
4. `CHECK DONE` が表示され、車輪が停止するまで待ちます。
5. 本体を車輪や可動部から離れた位置で持ち、台から下ろして床の上でできるだけ垂直に保持します。
6. 周囲の安全を確認して右上ボタンを押し、倒立制御を開始します。

車輪が回転しない、回転方向が異常、異音がする、または引っ掛かりがある場合は、倒立制御を開始しないでください。本体のバッテリーを外して原因を確認してください。

## ボタンとスティックの割り当て

| 操作 | 動作 |
| --- | --- |
| 右上ボタン | 倒立制御を開始／停止します。 |
| 左上ボタン | 通常モードと方向基準モードを切り替えます。 |
| 右スティック上下 | 前進／後進します。 |
| 右スティック左右 | 左右へ平行移動します。 |
| 左スティック左右 | 左右旋回します。 |
| 左スティック上下 | 前後ドリフトを抑えるため、傾きの基準を補正します。 |

## 前後ドリフトの補正

前後へドリフトする場合は、左スティック上下で傾きの基準を補正します。左スティック上下は短く操作し、少しずつ調整してください。倒したままにすると補正が連続して変化するため注意してください。

## 移動方向モード

### 通常モード

起動時のモードです。本体の現在の向きを基準に、右スティックで前後・左右へ移動します。

### 方向基準モード

左上ボタンで方向基準モードへ切り替えると、その瞬間の本体の向きが基準方向として記憶されます。このモードでは本体が旋回しても、右スティックによる前後・左右移動は記憶した基準方向に対して行われます。

もう一度左上ボタンを押すと通常モードへ戻ります。基準方向を設定し直す場合は、一度通常モードへ戻し、希望する向きで再び左上ボタンを押してください。

## 終了手順

1. 本体が倒れないように保持します。
2. 右上ボタンを押して倒立制御を停止します。
3. 車輪が停止したことを確認し、本体のバッテリーを必ず外します。
4. バッテリーを外してからコントローラーの電源を切ります。

## 異常時の対応

異音、異常な回転、引っ掛かり、予期しない動作を感じた場合は、ただちに本体を安全に保持して倒立制御を停止してください。車輪の停止を確認してから本体のバッテリーを外し、原因を確認します。通電したまま無人で放置しないでください。
